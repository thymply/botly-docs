# Datenschutzerklärung

## Cookies

Botly nutzt ausschließlich **technisch notwendige Cookies**:

- **Session-Cookie** — Für Login und Sitzungsverwaltung
- **Locale-Cookie** — Für die Spracheinstellung (DE/EN)

Es werden **keine** Tracking-Cookies, Analytics-Cookies oder Werbe-Cookies verwendet.

Beim ersten Besuch erscheint ein Cookie-Banner der darüber informiert. Nach Klick auf "Verstanden" wird die Information in localStorage gespeichert.
